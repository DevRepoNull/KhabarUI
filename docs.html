معماری و شروع

🚀 معرفی و نحوه استفاده در پروژه

قالب KhabarUI بر پایه HTML5، Tailwind CSS v3 و Vanilla JavaScript مهندسی شده است. تمامی اسکریپت‌ها و استایل‌ها به صورت کاملاً لوکال و آفلاین طراحی شده‌اند تا در هر محیطی (ASP.NET، لاراول، نود یا حتی به صورت لوکال با پروتکل file://) بدون نقص اجرا شوند.

۱. اتصال استایل‌ها (CSS)

فایل اصلی استایل‌ها در مسیر assets/css/style.css قرار دارد.

۲. بارگذاری اسکریپت‌ها

دو فایل components.js و main.js در انتهای <body> لود می‌شوند.

۳. ساختار کاملاً راست‌چین

تگ ریشه باید دارای خصوصیت‌های <html lang="fa" dir="rtl"> باشد.

ماژول جاوااسکریپت

🗂️ سیستم تب‌های تعاملی (NewsComponents.initTabs)

پشتیبانی کامل از استاندارد ARIA، سوییچ با کلیدهای جهت‌نما (Arrow Keys)، کلیدهای Home و End در محیط راست‌چین

محتوای تب تازه‌ترین‌ها: لیست آخرین رویدادهای مخابره شده طی ۲ ساعت اخیر با اتصال به دیتابیس به صورت لحظه‌ای.
محتوای تب پربازدیدترین‌ها: بیشترین اخبار مطالعه شده توسط کاربران در طول ۲۴ ساعت گذشته.
محتوای تب ویژه تحریریه: یادداشت‌ها و سرمقاله‌های منتخب دبیران سرویس خبرگزاری رصد.
JavaScript Integration 
// راه‌اندازی تب‌ها توسط ماژول داخلی NewsComponents
const container = document.getElementById('demo-tabs-container');
window.NewsComponents.initTabs(container, (activeTabName) => {
    console.log('تب فعال شد:', activeTabName);
});
ابزار تاریخ و زمان

📅 انتخاب‌گر تاریخ شمسی جلالی (Jalali Datepicker)

کتابخانه سبک و آفلاین برای انتخاب تاریخ‌های خورشیدی در فرم‌های جستجو، فیلتر آرشیو و انتشار خبر در پنل مدیریت

فقط کافی است ویژگی data-jdp را به هر فیلدی اضافه کنید.

نحوه استفاده در کدهای شما 
<!-- 1. اینکلود کردن استایل و اسکریپت جلالی -->
<link rel="stylesheet" href="assets/css/jalali-datepicker.min.css" />
<script src="assets/js/libs/jalali-datepicker.min.js"></script>

<!-- 2. اینپوت با اتریبیوت data-jdp -->
<input type="text" data-jdp placeholder="انتخاب تاریخ خورشیدی..." />

<!-- 3. اجرای ناظر تاریخ در اسکریپت -->
<script>
  jalaliDatepicker.startWatch({
      minDate: "attr",
      maxDate: "attr"
  });
</script>
اعتبارسنجی فرم

🛡️ اعتبارسنجی فرم‌ها با Just-Validate و پیام‌های فارسی

اعتبارسنجی فرم‌ها با استایل‌های منطبق بر تم رصد بدون وابستگی به جی‌کوئری

JavaScript Integration 
// نمونه اتصال JustValidate به فرم
const validator = new JustValidate('#docs-demo-form', {
    errorFieldCssClass: ['!border-rose-500', '!ring-rose-500/20'],
    errorLabelCssClass: ['text-rose-500', 'text-[0.6875rem]', 'font-semibold', 'mt-1']
});

validator
    .addField('#docs-email-input', [
        { rule: 'required', errorMessage: 'وارد کردن آدرس ایمیل الزامی است.' },
        { rule: 'email', errorMessage: 'فرمت آدرس ایمیل وارد شده نامعتبر است.' }
    ])
    .addField('#docs-pass-input', [
        { rule: 'required', errorMessage: 'رمز عبور نمی‌تواند خالی باشد.' },
        { rule: 'minLength', value: 6, errorMessage: 'رمز عبور حداقل باید ۶ کاراکتر باشد.' }
    ])
    .onSuccess((event) => {
        event.preventDefault();
        window.showToast('فرم با موفقیت اعتبارسنجی شد!', 'success');
    });

ناوبری هوشمند

🧭 معماری مگامنو (Mega Menu)

توضیح خصوصیات داده‌ای (Data Attributes) مورد استفاده در ناوبری برای نمایش زیرمنوهای تمام‌عرض

سیستم مگامنو در KhabarUI از طریق سه خصوصیت کلیدی کنترل می‌شود:

  • data-mega-item: بر روی المان والد تگ <li> در منو قرار می‌گیرد.
  • data-mega-trigger="key": بر روی لینک فعال‌کننده منو قرار می‌گیرد.
  • data-mega-panel="key": بر روی پنل بازشونده با همان کلید تعریف می‌شود.

ماژول NewsComponents.initMegaMenu(navElement) به طور خودکار رویدادهای ماوس (Hover)، تاخیر در بستن برای ارگونومی بهتر و کلید Escape را مدیریت می‌کند.
